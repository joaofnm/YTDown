# YTDown
Esse foi um projeto realizado para um trabalho da universidade.

Nesse projeto você comsegue realizar downloads de videos do youtube
Para rodar o projeto:

para rodar no Linux:
  python -m venv venv
  source venv/bin/activate
  pip install -r requirements
  python3 main.py

Para o MacOs
abaixar em o app em Releases, ou executar os mesmos passos do Linux
